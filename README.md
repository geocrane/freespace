# FreeSpace

Анализатор дискового пространства для АРМ и DataLab.
Показывает, чем занято место, находит большие файлы и одноимённые папки
(например, все `venv` разом) и убирает найденное в корзину — с возможностью
вернуть.

Основной интерфейс — веб: он одинаково работает на АРМ и в
DataLab контейнере с Jupyter.

## Быстрый старт

Скрипты сами создадут виртуальное окружение,
поставят зависимости при первом запуске, подберут свободный порт и откроют
браузер. Нужен только Python 3.10+.

| Где | Что сделать |
|---|---|
| **Windows** | двойной клик по `start.bat` |
| **DataLab** | открыть `start.ipynb`, вписать токен SberOSC в «Шаг 1», выполнить «Шаг 2» |

В тетрадке только две строки — `start(TOKEN)` и `stop()`; всё, что за ними стоит
(установка зависимостей из индекса портала, подбор порта, адрес за
`jupyter-server-proxy`), живёт в `freespace/notebook.py`.

## Запуск через консоль

```sh
python -m freespace.web
```

Команда печатает адрес — откройте его в браузере.


### Переменные окружения

| Переменная | Что делает |
|---|---|
| `FREESPACE_CACHE_DIR` | каталог для снимков вместо системного по умолчанию |
| `FREESPACE_ROOTS` | список предлагаемых корней через `:` вместо автоопределения |
| `FREESPACE_ROOT_PATH` | префикс URL |

Первым в списке корней всегда идёт домашний каталог: документы, загрузки и
рабочие файлы, и разбирать место почти всегда нужно именно там — на диске
целиком половина принадлежит системе и всё равно не удаляется.

## Как работать

### 1. Просканировать

В поле сверху — путь к папке или диску; под ним кнопками перечислены тома и
домашний каталог со свободным местом. Нажмите **«Сканировать»**.

- Идёт обход `os.scandir` очередью каталогов: узкое место здесь
  — задержка ввода-вывода, а не процессор, и на сетевых дисках выигрыш даёт
  именно большое число одновременных запросов.
- Виден прогресс. **«Отмена»** прерывает обход, но не выбрасывает результат —
  на экране останется то, что успели собрать.
- Если этот корень уже разбирали в последние сутки, результат покажется
  мгновенно из сохранённого снимка, с пометкой возраста данных.
  **«Пересканировать всё»** обходит заново, не доверяя снимку.


### 2. Смотреть карту и содержимое

Слева — **treemap**, плитки, пропорциональные размеру.

- Клик по папке — открыть её.
- Клик по файлу — подсветить его строку в списке справа и прокрутить к ней.
- Плитка «остальное» собирает мелочь сверх лимита: она ничего не изображает и
  никуда не ведёт.

Справа вкладка **«Содержимое»**: состав текущей папки с размерами и долей от
родителя.

### 3. Искать

Вкладка **«Поиск»** ищет по уже просканированному дереву — мгновенно, без
повторного обхода.

| Поле | Смысл |
|---|---|
| строка запроса | имя целиком, часть имени или шаблон вида `*.iso` |
| режим | «часть имени» / «по шаблону с `*`» (понимает `*` и `?`) / «имя целиком» |
| тип | и папки, и файлы / только папки / только файлы |
| вид файлов | видео, аудио, изображения, архивы, образы дисков, документы, код, установщики, базы данных, прочее |
| «больше, МБ» | нижняя граница размера |
| **скрывать вложенные результаты** | убирает находки, лежащие внутри других находок: если папка попала в результат целиком, её подпапки попали автоматически, а удалять надо внешнюю |
| **объединять одинаковые имена** | сводит одноимённые находки в одну строку — «сколько у меня всего `venv` и сколько они занимают» одним ответом; строка разворачивается в список самих папок |
| **искать только в открытой папке** | сужает поиск до текущего поддерева |

### 4. Готовые наборы условий

Шаблоны под полем поиска заполняют фильтры и сразу ищут:

| Набор | Что находит |
|---|---|
| файлы больше 100 МБ | все крупные файлы |
| видео | по расширению |
| архивы | по расширению |
| `__pycache__` | папки байткода, с группировкой |
| автосохранения Jupyter | `.ipynb_checkpoints` |
| виртуальные окружения | шаблон `*venv` — ловит и `venv`, и `.venv` |


### 5. Отметить и удалить пачкой

Панель над
списком показывает, сколько объектов отмечено и сколько они занимают;
**«выбрать все»** отмечает весь список, **«Удалить отмеченные»** уносит всё в
корзину. 


### 6. Корзина

Удалённое переезжает в `~/.freespace-trash`

На вкладке **«Корзина»** видно, что удалено, откуда и сколько занимает. Рядом с
каждой записью — **«Восстановить»**: исходный путь лежит в `meta.json`, объект
вернётся на место. Кнопка **«Очистить корзину»** удаляет файлы полностью.

Место освобождается только после очистки, поэтому сама корзина остаётся в
списках отдельной строкой с размером.


### Частые задачи

| Задача | Как |
|---|---|
| «Куда делось место на диске» | «Сканировать» домашний каталог → смотреть карту, проваливаться в крупные плитки |
| «Сколько весят все мои venv» | «Поиск» → набор «виртуальные окружения» → включить «объединять одинаковые имена» |
| «Убрать весь питоновский мусор» | наборы `__pycache__` и «автосохранения Jupyter» → «выбрать все» → «Удалить отмеченные» |
| «Найти старые образы дисков» | «Поиск» → вид файлов «образы дисков» → «больше, МБ» = 500 |
| «Разобрать одну папку» | открыть её на карте → галочка «искать только в открытой папке» |
| «Вернуть удалённое» | вкладка «Корзина» → «Восстановить» |
| «Освободить место окончательно» | вкладка «Корзина» → «Очистить корзину» |

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Не установлен uvicorn» | `pip install -r requirements.txt` |
| порт занят | `python -m freespace.web --port auto` |
| Windows не находит Python | Установить последнюю версию со SberOSC|
| в контейнере не ставятся зависимости | впишите токен SberOSC в ячейку «Шаг 1» |
| в контейнере пустая страница или 404 | в окружении нет `jupyter-server-proxy`; ячейка запуска 
| в контейнере сервер не поднялся | полный лог рядом с проектом: `.freespace-server.log` |
